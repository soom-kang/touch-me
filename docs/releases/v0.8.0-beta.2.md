# Touch Me v0.8.0-beta.2

## English

This beta makes safety stops easier to understand and improves packaging diagnostics:

- Sleep, session inactivity and display changes show why mapping stopped and ask you to check the target and permissions before starting manually. The existing stop policy is preserved; a device-mode restoration error stays visible.
- Packaging stops with a rebuild instruction when app metadata is missing, unreadable or invalid, before replacing an existing image.
- Existing regression tests cover packaging failures, coordinate safety and click sequences. The packaging fixture now resolves temporary paths so its permission-error case also runs on macOS.

The scope remains one ZEUSLAP P16KT on Apple Silicon with macOS 26 (Tahoe) or later. Build 12 uses ad hoc signing without Developer ID signing or Apple notarization. Downloaded apps may require first-launch approval and renewed Input Monitoring and Accessibility permission. Follow [Apple's manual approval guidance](https://support.apple.com/en-us/102445) when available.

Download `touch-me-0.8.0-beta.2-arm64.dmg` and its `.sha256` file together, then verify before installing:

```bash
shasum -a 256 -c touch-me-0.8.0-beta.2-arm64.dmg.sha256
```

The personal Homebrew Tap uses:

```bash
brew install --cask soom-kang/touch-me/touch-me
```

Before upgrading or removing an app, select **Stop mapping**, confirm device-mode restoration, then **Quit** normally. Stop the operation if restoration fails. Preserve a manually installed app outside Applications before installing through Homebrew. See the [Homebrew runbook](https://github.com/soom-kang/touch-me/blob/main/docs/Homebrew.md).

### Verification and limits

On 2026-10-07 (`Asia/Seoul`), 14 Swift tests passed. The first Python run passed 17 of 18 tests; one permission-error fixture missed macOS's `/var` → `/private/var` path alias. After resolving the fixture path, all 18 Python tests passed. No new test infrastructure or dependencies were added.

One release build and one packaging run produced build 12. Release compilation, strict ad hoc signature verification, exact license and icon comparison, bundle metadata, arm64 packaging, DMG integrity and SHA-256 verification passed. Command Line Tools emitted non-fatal linker search-path warnings.

Cask Ruby syntax passed. Homebrew style inspected an identical `.rb` Cask preview and reported no offenses. The `.rb.in` template was excluded by the style runner; a preview inside hidden `.build` used generic Ruby rules, so the final preview was checked under a normal `Casks` path.

Homebrew installation, Gatekeeper approval, GUI behavior, real-device mapping and login launch were not exercised for this candidate. Historical device results apply to earlier builds. Abnormal-exit device-mode recovery remains unimplemented; reopening the app does not prove restoration of the pre-crash mode.

## 한국어

안전 중단 안내와 패키징 오류 메시지를 보강했습니다.

- 절전, 사용자 세션 비활성화와 화면 변경으로 중지되면 이유를 안내하고, 대상과 권한을 확인한 뒤 직접 매핑을 시작하도록 표시합니다. 기존 중단 정책을 유지하며 장치 모드 복구 오류도 그대로 표시합니다.
- 앱 metadata가 없거나 읽을 수 없거나 잘못된 형식이면 기존 이미지를 대치하기 전에 중단하고 재빌드 명령을 안내합니다.
- 기존 회귀 테스트는 패키징 실패, 좌표 안전성과 클릭 시퀀스를 다룹니다. macOS에서도 권한 오류 사례가 실행되도록 기존 fixture의 임시 경로를 정규화했습니다.

지원 범위는 Apple Silicon과 macOS 26(Tahoe) 이상에서 사용하는 ZEUSLAP P16KT 한 대입니다. Build 12는 Developer ID 서명과 Apple 공증 없이 ad hoc 서명을 사용합니다. 다운로드 앱의 첫 실행 승인과 입력 모니터링·손쉬운 사용 재승인이 필요할 수 있습니다. 승인 경로가 제공되면 [Apple의 수동 승인 안내](https://support.apple.com/en-us/102445)를 따르세요.

DMG와 `.sha256` 파일을 함께 다운로드하고 위의 checksum 명령으로 확인한 뒤 설치하세요. Homebrew 설치 명령도 위와 같습니다. 업데이트·제거 전에는 **매핑 중지 → 장치 모드 복구 확인 → 정상 종료** 순서로 준비합니다. 복구가 실패하면 작업을 중단하세요. Homebrew 설치 전에 수동 설치한 앱을 Applications 밖에 보존합니다. 자세한 절차는 [Homebrew runbook](https://github.com/soom-kang/touch-me/blob/main/docs/Homebrew.ko.md)을 확인하세요.

### 검증 결과와 한계

2026-10-07(`Asia/Seoul`)에 Swift 테스트 14개가 통과했습니다. 첫 Python 실행에서는 18개 중 17개가 통과했습니다. 나머지 권한 오류 fixture는 macOS의 `/var` → `/private/var` 경로 차이로 오류를 주입하지 못했습니다. 경로 정규화 후 Python 테스트 18개가 모두 통과했습니다. 새 테스트 인프라나 dependency는 추가하지 않았습니다.

Release build와 패키징을 각각 한 번 실행해 build 12를 생성했습니다. Release 컴파일, strict ad hoc 서명, 라이선스·아이콘 내용 일치, bundle metadata, arm64 패키징, DMG 무결성과 SHA-256 검사를 통과했습니다. Command Line Tools의 linker search-path 경고는 빌드를 중단하지 않았습니다.

Cask Ruby syntax와 동일한 `.rb` 초안의 Homebrew style 검사를 통과했습니다. Style runner가 `.rb.in`을 제외했고 숨김 `.build` 경로에서는 일반 Ruby 규칙을 적용했으므로, 최종 초안은 일반 `Casks` 경로에서 한 파일을 검사해 오류 없이 통과했습니다.

이번 후보의 Homebrew 설치, Gatekeeper 승인, GUI, 실기기 매핑과 로그인 실행은 수행하지 않았습니다. 과거 장치 검증 결과는 이전 build에 해당합니다. 비정상 종료 후 장치 모드 복구는 여전히 구현되지 않았으며, 앱 재실행만으로 충돌 전 모드 복구를 확인할 수 없습니다.
