# Touch Me v0.8.0-beta.12

## English

Status: **PUBLISHED — 2026-10-28 17:01:23 KST / 08:01:23 UTC**.
Public DMG and checksum bytes match the locally verified artifact. The published
Tap Cask, exact-version allowlist and bilingual guidance match the reviewed checkout.

### Changes

- Add native two-finger back/forward in Safari and Chrome: swipe right to go back
  and left to go forward. The browser owns horizontal scrolling, history edges,
  transition progress and reversal cancellation. Enable two-finger **Swipe between
  pages** in macOS; Touch Me does not change that setting or invert the direct-touch
  direction with **Natural scrolling**.
- Emit precise phased scroll events at the starting target with an isolated
  undocumented companion gesture format. Page swiping requires macOS 26 and a
  successful event-conversion check. Regular scrolling remains available if the
  companion format is unavailable; no keyboard navigation is substituted.
- Fix touch input after USB recovery by selecting digitizer contacts before the
  initial HID state read. An inactive mouse-emulation channel no longer prevents
  the all-fingers-lifted state when digitizer contacts are available.
- Preserve click, drag, pinch and three-finger Mission Control/Spaces behavior.
  Update bilingual help, documentation and packaged instructions. No dependency,
  driver or daemon is added.

### Validation and limits

Runtime source and tests are unchanged from `294982a`. The existing 60-test PASS
(39 Platform + 21 Core) is reused after a source comparison. The updated DMG
instructions pass the existing 26 packaging tests.

Physical acceptance is **PASS_USER_REPORTED** on macOS 26.7.2, Safari 27.2 and
Chrome 156.0.8078.74. Build 36 covers navigation, repeat/reversal, history edges,
horizontal and nested scrolling, starting target, existing inputs, Stop and lock.
Build 38 covers the USB fix in both browsers, restored input, pinch/drag/reversal,
repeated three-finger actions and P16KT targeting. The full build 36 matrix was
not repeated on build 38. The final stopped state was separately confirmed in the
GUI. See the [candidate QA record](../qa/automated-tests.md#native-page-swipe-candidate--2026-10-28).

- Safari's containment test navigated with both the physical trackpad and P16KT;
  Chrome blocked navigation with both. This is browser parity, not a guarantee
  that every browser blocks page navigation for that CSS policy.
- Release build 39 passes strict signature, exact certificate, bidirectional
  installed-app designated requirement, arm64, metadata, license/icon, DMG
  integrity/checksum and read-only inner-app byte comparison.
- Release-build GUI/device acceptance, installation/upgrade and permission
  retention for beta.12, fresh Gatekeeper and a receiving Mac are **NOT_RUN**.
- The optional Natural scrolling on/off comparison is **NOT_RUN**.
- Online Homebrew audit remains **BLOCKED** under the existing trust-preserving
  deferral. Anonymous public DMG/checksum downloads pass exact byte, size and
  GitHub digest comparison. The public Tap matches the reviewed Cask, exact
  prerelease allowlist and bilingual guidance. Cask syntax and current Homebrew
  style rules pass using existing compatible gems, not the exact locked toolchain.

The existing maintainer certificate and bundle identifier are retained. This is
not a Developer ID signature or Apple notarization. Installed beta.11/build 33,
preferences, recovery records, prior releases and trust settings are preserved.
The selected Cask is trusted; the whole Tap is not. No app upgrade or trust change
is part of this release task.

### 변경 사항

- Safari와 Chrome에서 두 손가락으로 오른쪽을 밀면 뒤로, 왼쪽을 밀면 앞으로
  이동합니다. 가로 스크롤, 방문 기록 경계, 전환 표시와 되돌림 취소는 브라우저가
  판단합니다. macOS의 ‘페이지 쓸어넘기기’에서 두 손가락 동작을 켜야 합니다.
  Touch Me는 설정을 바꾸거나 ‘자연스러운 스크롤’에 따라 터치 방향을 반전하지 않습니다.
- 시작 대상을 유지하는 정밀 스크롤 단계와 어댑터에 한정한 비공개 보조 제스처
  이벤트를 전송합니다. 페이지 이동은 macOS 26에서 이벤트 변환 검사를 통과해야
  사용할 수 있습니다. 지원되지 않으면 일반 스크롤을 유지하며 단축키로 대체하지 않습니다.
- 최초 HID 상태를 읽기 전에 digitizer 접점을 선택하도록 USB 복구를 수정합니다.
  Digitizer 접점이 있는 장치에서 비활성 마우스 에뮬레이션 채널이 전체 손가락
  해제를 막아 새 입력이 멈추는 문제를 해결합니다.
- 기존 클릭·드래그·핀치·세 손가락 Mission Control/Spaces 동작을 유지하고
  영문·국문 도움말, 문서와 DMG 안내를 갱신합니다. 새 dependency, driver,
  daemon은 추가하지 않습니다.
