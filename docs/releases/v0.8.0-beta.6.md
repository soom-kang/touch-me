# Touch Me v0.8.0-beta.6

## English

Prepublication candidate record — 2026-10-09 (`Asia/Seoul`):
**CANDIDATE / NOT_PUBLISHED** at this checkpoint.

### Changes and inherited behavior

This is a redistribution with completed QA documentation. There are no
runtime-code changes since beta.5. The strict recovery journal is unchanged:
recovery requires the same boot and continuously attached verified HID/USB
identities, location and descriptor, with a proven-dead previous owner. Original
mode readback and record clearing complete before mapping resumes; an uncertain
record or changed attachment blocks mapping without guessed writes.
