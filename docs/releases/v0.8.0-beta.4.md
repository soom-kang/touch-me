# Touch Me v0.8.0-beta.4

## English

Two-finger scrolling no longer sends a preliminary click when the first finger reaches the panel before the second.

- A one-finger tap clicks when the finger lifts. Holding a stationary finger does not press the mouse button.
- Movement more than 8 screen-coordinate units from the starting position begins a drag. A second finger added after that point does not switch the gesture to scrolling; the drag continues to track the original contact.
- Two contacts detected before dragging cancel the pending tap and scroll using their midpoint. A finger left after scrolling cannot become a new click or drag. Lift all fingers before switching gestures.
- Missing or invalid contact data cancels the pending tap. Stop and other rejected gestures release only an actual held button. Drag-start events cannot inherit a preceding tap's double-click count.

Support remains one ZEUSLAP P16KT (`0x0457:0x0819`) on Apple Silicon with macOS 26 (Tahoe) or later and an eligible external display. This beta uses ad hoc signing without Developer ID signing or Apple notarization. Updates may require renewed Input Monitoring and Accessibility approval.

Download `touch-me-0.8.0-beta.4-arm64.dmg` and its `.sha256` file together and verify before installing:

```bash
shasum -a 256 -c touch-me-0.8.0-beta.4-arm64.dmg.sha256
```

Install through the existing personal Tap:

```bash
brew install --cask soom-kang/touch-me/touch-me
```

Before updating or removing the app, select **Stop mapping**, confirm device-mode restoration, then quit normally. If restoration fails, stop the operation and retry recovery with the panel on the same USB port. See the [Homebrew guide](https://github.com/soom-kang/touch-me/blob/v0.8.0-beta.4/docs/Homebrew.md).

### Verification and limits

On 2026-10-09 (`Asia/Seoul`), all 14 existing Swift tests passed after the gesture change. The six existing gesture test cases were updated; no new test files or infrastructure were added. Tests cover delayed taps, the 8-unit boundary, staggered two-finger input, drag contact ownership, release and rejected input. The release preparation does not rerun the suite unless gesture code changes.

The user reported that build 20 scrolled horizontally and vertically without additional downs, and that taps, double-clicks, dragging and original-finger tracking were normal (`PASS_USER_REPORTED`). The candidate still displayed `0.8.0-beta.3`. Its event trace and running process were not directly observed during the check. This report does not establish device behavior for every panel or for the new build 21 artifact.

Build 21 native/device, Homebrew installation, Gatekeeper, sleep/wake and full logout/login checks are `NOT_RUN`. HID contact ownership uses descriptor slots; broader device behavior is unverified. Abnormal-exit device-mode recovery remains unimplemented. No dependency, CI, trust, privacy or login-item change is part of this release.

### Artifact verification

One release build and one packaging run in a separate checkout produced build 21 with `TouchMeReleaseVersion=0.8.0-beta.4`. Warnings-as-errors compilation, strict ad hoc signature verification, bundle identity/version, exact license/icon content, arm64 packaging, `hdiutil verify` and the SHA-256 sidecar check passed. The 22 compilation and packaging inputs matched the frozen manifest in both checkouts. Existing Command Line Tools linker search-path warnings were non-fatal. The working checkout's build 20 and the Applications app were preserved.

Frozen DMG SHA-256: `ebc23abfa4ee9b8e196bd41edb676ed671b1200d63e4eca677c92eba2bbb7b89`.

Homebrew 7.0.9 style checked the actual Tap `Casks/touch-me.rb`: one file inspected, no offenses. The first attempt could not write its cache before linting; a retry with temporary task-scoped caches completed. No persistent Homebrew setting or trust was changed.

Public download and Homebrew publication/audit results are recorded on the [release](https://github.com/soom-kang/touch-me/releases/tag/v0.8.0-beta.4) after those checks run. Local artifact checks do not establish publication or installed behavior.

## 한국어

두 손가락 스크롤에서 첫 손가락이 먼저 닿아도 스크롤 전에 클릭을 보내지 않도록 수정했습니다.

- 한 손가락 탭은 손을 뗄 때 클릭합니다. 움직이지 않고 누른 상태만으로 마우스 버튼을 누르지 않습니다.
- 처음 위치에서 화면 좌표 8단위를 초과해 움직이면 드래그를 시작합니다. 그 뒤 두 번째 손가락을 추가해도 스크롤로 바뀌지 않고 최초 접촉을 따라갑니다.
- 드래그 전에 두 접촉이 감지되면 대기 탭을 취소하고 중간점 이동으로 스크롤합니다. 스크롤 후 남은 손가락은 새 클릭이나 드래그가 되지 않습니다. 동작을 바꾸려면 손가락을 모두 뗀 뒤 다시 시작하세요.
- 접촉 정보가 없거나 유효하지 않으면 대기 탭을 취소합니다. Stop과 입력 거부는 실제 누른 버튼만 해제합니다. 드래그 시작 이벤트가 이전 탭의 더블 클릭 횟수를 이어받지 않도록 처리했습니다.

지원 범위는 Apple Silicon과 macOS 26(Tahoe) 이상에서 사용하는 ZEUSLAP P16KT(`0x0457:0x0819`) 한 대와 조건에 맞는 외부 화면입니다. Developer ID 서명과 Apple 공증 없이 ad hoc 서명을 사용합니다. 업데이트 후 입력 모니터링·손쉬운 사용 재승인이 필요할 수 있습니다.

DMG와 `.sha256` 파일을 함께 받아 위 명령으로 checksum을 확인하세요. Homebrew 설치 명령도 위와 같습니다. 업데이트·제거 전에는 **매핑 중지 → 장치 모드 복구 확인 → 정상 종료** 순서를 따릅니다. 복구가 실패하면 작업을 중단하고 같은 USB 포트에서 복구를 재시도하세요. [Homebrew 안내](https://github.com/soom-kang/touch-me/blob/v0.8.0-beta.4/docs/Homebrew.ko.md)를 확인하세요.

### 검증 결과와 한계

2026-10-09(`Asia/Seoul`) 제스처 수정 후 기존 Swift 테스트 14개가 통과했습니다. 기존 제스처 테스트 6개를 수정했으며 새 테스트 파일이나 인프라는 추가하지 않았습니다. 탭 지연, 8단위 경계, 엇갈린 두 접촉, 드래그 접촉 추적, 입력 해제와 거부를 확인했습니다. 제스처 코드가 바뀌지 않으면 배포 준비에서 suite를 반복하지 않습니다.

사용자는 build 20에서 가로·세로 스크롤 중 누름 횟수가 늘지 않고 탭·더블 클릭·드래그와 최초 손가락 추적이 정상이라고 보고했습니다(`PASS_USER_REPORTED`). 후보의 표시 버전은 아직 `0.8.0-beta.3`였습니다. 확인 중 실제 이벤트나 실행 프로세스를 직접 관찰하지 않았으므로 모든 패널이나 새 build 21 산출물의 실기 동작을 증명하지는 않습니다.

Build 21의 native/device·Homebrew 설치·Gatekeeper·절전/복귀·실제 로그아웃/로그인 검사는 `NOT_RUN`입니다. 접촉 추적은 HID descriptor slot을 사용하며 다른 장치의 동작은 미검증입니다. 비정상 종료 후 장치 모드 복구는 구현되지 않았습니다. 이번 배포는 dependency·CI·trust·개인정보 권한·로그인 항목을 변경하지 않습니다.

### 산출물 검증

별도 checkout에서 release 빌드와 패키징을 각각 한 번 실행해 `TouchMeReleaseVersion=0.8.0-beta.4`인 build 21을 생성했습니다. Warnings-as-errors 컴파일, strict ad hoc 서명, bundle 식별자·버전, 정확한 라이선스·아이콘 내용, arm64 패키징, `hdiutil verify`와 SHA-256 sidecar 검사를 통과했습니다. 두 checkout의 컴파일·패키징 입력 22개가 확정한 manifest와 일치했습니다. 기존 Command Line Tools의 linker search-path 경고는 빌드를 중단하지 않았습니다. 작업 checkout의 build 20과 Applications 앱은 보존했습니다.

확정한 DMG SHA-256은 `ebc23abfa4ee9b8e196bd41edb676ed671b1200d63e4eca677c92eba2bbb7b89`입니다.

Homebrew 7.0.9 style은 실제 Tap의 `Casks/touch-me.rb` 한 파일을 검사해 오류 없이 통과했습니다. 첫 시도는 lint 시작 전 cache 쓰기 제한으로 실패했고, 작업용 임시 cache로 재시도해 완료했습니다. Homebrew의 영구 설정과 trust는 변경하지 않았습니다.

공개 다운로드와 Homebrew 게시·audit 결과는 해당 검사가 끝난 뒤 [release](https://github.com/soom-kang/touch-me/releases/tag/v0.8.0-beta.4)에 기록합니다. 로컬 산출물 검사만으로 게시나 설치 앱 동작을 확인한 것은 아닙니다.
