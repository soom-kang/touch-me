# Touch Me v0.8.0-beta.1

## English

Touch Me adds an app language selector for **English** and **한국어**. English is the default. A language change applies immediately to settings, menus, status messages and open test windows, and the choice is saved for the next launch. The current mapping session and target selection stay in place.

This beta supports Apple Silicon with macOS 26 (Tahoe) or later and targets one ZEUSLAP P16KT connected by USB-C. It uses ad hoc signing without a Developer ID signature or Apple notarization. macOS may block first launch or require renewed Input Monitoring and Accessibility approval after an update. Follow [Apple's manual approval guidance](https://support.apple.com/en-us/102445) when available.

Download `touch-me-0.8.0-beta.1-arm64.dmg` and its `.sha256` file together. Verify the checksum before installing:

```bash
shasum -a 256 -c touch-me-0.8.0-beta.1-arm64.dmg.sha256
```

The personal Homebrew Tap uses:

```bash
brew install --cask soom-kang/touch-me/touch-me
```

Before updating or removing an app, select **Stop mapping**, confirm device-mode restoration, then **Quit** normally. Stop the operation if restoration fails. Preserve an existing manually installed app outside Applications before a Homebrew installation. See the [Homebrew runbook](https://github.com/soom-kang/touch-me/blob/main/docs/Homebrew.md).

Build 11 passed release compilation with warnings as errors, exact project-license comparison, strict ad hoc signature verification, arm64 packaging, DMG integrity and SHA-256 verification, Cask syntax and Homebrew style. Packaging rejects an app whose license resource differs from the current project `LICENSE`.

GUI language switching, relaunch persistence, Gatekeeper approval for the downloaded app, physical-device mapping, login launch and Homebrew installation were not exercised for this candidate. Historical device results in the README apply to earlier builds. No test code or app dependencies were added.

## 한국어

Touch Me에 **English**와 **한국어**를 선택하는 앱 언어 옵션을 추가했습니다. 기본값은 영어입니다. 변경한 언어는 설정, 메뉴, 상태 메시지와 열린 시험 창에 즉시 적용되며 다음 실행에도 유지됩니다. 현재 매핑 세션과 대상 선택은 유지합니다.

이 beta는 Apple Silicon과 macOS 26(Tahoe) 이상을 지원 범위로 하며, USB-C로 연결한 ZEUSLAP P16KT 한 대를 대상으로 합니다. Developer ID 서명과 Apple 공증 없이 ad hoc 서명을 사용합니다. macOS가 첫 실행을 차단하거나 업데이트 후 입력 모니터링·손쉬운 사용 재승인을 요구할 수 있습니다. 승인 경로가 제공되면 [Apple의 수동 승인 안내](https://support.apple.com/en-us/102445)를 따릅니다.

`touch-me-0.8.0-beta.1-arm64.dmg`와 `.sha256` 파일을 함께 다운로드하고, 위의 checksum 명령으로 확인한 뒤 설치하세요. 개인 Homebrew Tap의 설치 명령은 위와 같습니다.

업데이트·제거 전에 **매핑 중지**, 장치 모드 복구 확인, 정상 **종료** 순서로 준비합니다. 복구가 실패하면 작업을 중단하세요. Homebrew 설치 전에 기존 수동 설치 앱을 Applications 밖에 보존합니다. 자세한 절차는 [Homebrew runbook](https://github.com/soom-kang/touch-me/blob/main/docs/Homebrew.ko.md)을 확인하세요.

Build 11은 warnings-as-errors release 컴파일, 프로젝트 라이선스 내용 일치, strict ad hoc 서명, arm64 패키징, DMG 무결성·SHA-256, Cask syntax와 Homebrew style 검사를 통과했습니다. 앱의 라이선스가 현재 프로젝트 `LICENSE`와 다르면 패키징을 중단합니다.

이번 후보의 GUI 언어 전환, 재실행 후 선택 유지, 다운로드 앱의 Gatekeeper 승인, 실기기 매핑, 로그인 실행과 Homebrew 설치는 수행하지 않았습니다. README의 이전 장치 기록은 과거 build에 해당합니다. Test 코드와 앱 dependency는 추가하지 않았습니다.
