# Touch Me v0.8.0-beta.11

## English

Status: **ARTIFACT_PASS; NOT_PUBLISHED**.

### Changes

- Add two-finger pinch to zoom app content, with scroll/pinch arbitration and
  cancellation when contacts change. Pinch requires macOS 26 and a successful
  local event-format check; it can be disabled in settings.
- Add three-finger up for Mission Control and left/right for the next/previous
  Space. Each stroke executes once and requires full lift before another gesture.
  The default Control-Up/Left/Right shortcuts must be enabled.
- Preserve native arrow flags and pair Control down/up so consecutive strokes
  work without an intervening mouse click. Held physical modifiers or mouse
  buttons suppress new system commands.
- Track observed HID slot contact generations while preserving the existing
  tap-on-lift and drag ownership behavior.
- Update English/Korean settings help, documentation and packaged installation
  notes. No dependency, driver or daemon is added.

### Validation and limits

The gesture source is commit `f386a89`. Development build 32 on macOS 26.7.1
passed user-observed P16KT checks: repeated three-finger commands, both Space
boundaries, Safari 27.0, Preview 11.0 PDF/image and Chrome 156.0.8078.48 pinch,
Stop/restart, lock/unlock, USB reconnection, current four-display targeting and
final Stop. These results are recorded against that development executable in
the [gesture QA record](../qa/automated-tests.md#gesture-expansion--2026-10-25).

- The unchanged runtime source retains its 49-test PASS (30 Platform, 19 Core).
- Updated packaged instructions pass the existing 26 packaging tests.
- Release build 33 passes strict signature, exact certificate, arm64, metadata,
  license/icon, DMG integrity/checksum and read-only inner-app comparison.
- Public download and Tap checks are pending.
- Release-build GUI/device acceptance, installation/upgrade, permission retention
  for this upgrade, fresh Gatekeeper and a receiving Mac remain **NOT_RUN**.
- Online Homebrew audit remains **BLOCKED** under the trust-preserving deferral.
  Current selected-Cask and whole-Tap trust are both false; no trust change is made.
- Negative-origin P16KT placement, deliberate physical contact replacement and
  interruptions during an established drag have no new hardware acceptance.

This release keeps the existing maintainer certificate and bundle identifier.
It has no Developer ID signature or Apple notarization. Existing releases,
installed build 28, preferences, recovery records and trust settings are preserved.

## 한국어

상태: **ARTIFACT_PASS; NOT_PUBLISHED**.

### 변경 사항

- 두 손가락으로 앱 콘텐츠를 확대·축소하는 핀치를 추가합니다. 스크롤과 핀치를
  판별하고 접점이 바뀌면 취소합니다. 핀치는 macOS 26에서 이벤트 형식 검사를
  통과해야 사용할 수 있으며 설정에서 끌 수 있습니다.
- 세 손가락을 위로 밀면 Mission Control, 좌우로 밀면 다음·이전 Space로
  전환합니다. 한 동작에 한 번만 실행하며 다음 동작 전에 손을 모두 떼야 합니다.
  기본 Control+↑/←/→ 단축키가 켜져 있어야 합니다.
- 방향키 기본 플래그를 유지하고 Control 누름·해제를 짝지어 마우스 클릭 없이
  연속 전환할 수 있게 합니다. 물리적 modifier 키나 마우스 버튼을 누른 동안에는
  새 시스템 전환을 실행하지 않습니다.
- HID 슬롯에서 관찰한 접촉 세대를 구분합니다. 기존 탭 해제 시 클릭과 드래그
  접점 추적 방식은 유지합니다.
- 영문·국문 설정 도움말, 문서와 DMG 사용 안내를 갱신합니다. 새 dependency,
  driver, daemon은 추가하지 않습니다.
