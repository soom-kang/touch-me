# Touch Me v0.8.0-beta.8

## English

Status: **PUBLISHED** — 2026-10-12 01:41:21 UTC (10:41:21 KST).
[GitHub prerelease](https://github.com/soom-kang/touch-me/releases/tag/v0.8.0-beta.8).
Approved scope: new prerelease and existing Homebrew Tap update. Preserve the
installed app, recovery records, preferences, permissions and trust settings.

### Changes

- **TMQA-006:** Retry and Start confirm directory sync even when the active
  recovery record is absent. A sync error or a newly appeared record blocks
  Start. Record format and device feature I/O are unchanged.
- **TMQA-007:** Prepare the complete DMG/checksum pair in staging before
  replacing final files. Archive a valid previous pair with its original
  filenames and roll back ordinary file-move failures. An incomplete or
  mismatched previous pair is preserved and rejected. Rollback failure stops
  further moves and reports inspection paths. Separate renames do not guarantee
  atomicity across crashes, power loss or concurrent packaging runs.

### Preserved state and observation limit

Before/after inventories match for the installed app (five files), recovery
records (seven), preferences (one) and prior local `dist` artifacts (25).
Selected-Cask trust (`true`), whole-Tap trust (`false`), both checked developer
keys and the developer environment state match their baseline.

The shared trust-store file's raw hash changed during this window. The actor
and cause are **Unverified**. No trust/developer modification command, bypass
or store restoration was performed. Target settings match; whole-store byte
preservation is not established. Keep the current store and avoid overwriting
unrelated changes while this observation remains unresolved.

The requested additional read-only investigation checked current Git hook
configuration, the vendored style-tool source path, related concurrent isolated
QA evidence, current process metadata and narrowly timed shell-history/unified-log
queries. It found no supported writer attribution. A concurrent isolated trust
file is distinct from the shared store, and timestamp overlap does not prove a
cause. The actor and cause remain Unverified; no restoration or setting change
was attempted.

Build 26 GUI, physical-device behavior, mode readback, installation, upgrade,

ad hoc, without Developer ID or notarization. See the
[QA report](../qa/2026-10-12-qa-report.md) and [release runbook](../Homebrew.md).

## 한국어

상태: **PUBLISHED** — 2026-10-12 01:41:21 UTC(10:41:21 KST).
[GitHub prerelease](https://github.com/soom-kang/touch-me/releases/tag/v0.8.0-beta.8).
새 prerelease와 기존 Homebrew Tap 갱신을 승인받았습니다. 설치 앱, 복구 기록,
환경설정, 권한과 trust 설정은 보존합니다.

### 변경

- **TMQA-006:** Active recovery record가 없어도 Retry와 Start는 directory
  sync를 확인합니다. Sync 오류나 새 기록이 있으면 Start를 차단합니다.
  기록 형식과 장치 feature I/O는 유지합니다.
- **TMQA-007:** 최종 파일을 바꾸기 전에 staging에서 DMG/checksum 쌍을 완성합니다.
  유효한 이전 쌍은 원래 파일명으로 함께 보관하고 일반 파일 이동 오류는 되돌립니다.
  불완전하거나 checksum이 맞지 않는 이전 쌍은 보존하고 중단합니다. Rollback도
  실패하면 추가 이동을 멈추고 점검할 경로를 표시합니다. 개별 rename은 crash,
  전원 손실이나 동시 패키징까지 atomicity를 보장하지 않습니다.

### 산출물과 검증

위 표에 새 beta.8/build 26의 실행 파일과 DMG 식별을 기록했습니다. 별도 checkout에서
앱과 DMG를 각각 한 번 만들었고 native 산출물 검사를 통과했습니다. 기존 Swift
38개와 packaging 22개 PASS는 재사용했으며 suite를 다시 실행하지 않았습니다.
동결한 입력 43개 중 이전 QA 후보와 다른 것은 `VERSION`과 최종 Cask draft입니다.
Cask draft는 빌드에 사용되지 않으며 DMG 생성 후 정확한 digest를 반영했습니다.
[Input manifest](v0.8.0-beta.8-inputs.json)의 입력 43개는 tag를 만들기 전에 정확한
release commit과 일치함을 확인했습니다. 게시 후 익명 공개 DMG·sidecar의
bytes, 크기, digest와 checksum 텍스트도 동결 후보와 같았습니다. 실제 Cask
Ruby 문법과 동등한 Homebrew style 규칙은 통과했고 공개·검토·로컬 Tap은
`47a3e433`에 일치합니다. 로컬 Tap만 fast-forward로 갱신했으며 앱을 설치하거나
upgrade하지 않았습니다. 이전 release 7개, asset 14개와 tag ref 14개도 보존했습니다.

첫 style 실행은 source 디렉터리에서 시작해 exit 130으로 중단했고 Tap 디렉터리의
실행으로 바로잡아 통과했습니다. `brew style` front-end와 gem 설치·정리는
실행하지 않았습니다.

일반 online audit는 trust 보존을 위한 합의에 따라 **BLOCKED**입니다. 현재 선택
Cask는 trusted, 전체 Tap은 untrusted이며 변경하지 않습니다. 과거 beta.7의 trust
상태나 beta.6의 audit PASS를 이번 결과로 옮기지 않습니다.

### 상태 보존과 관측 한계

설치 앱 파일 5개, 복구 기록 7개, 환경설정 1개와 기존 로컬 `dist` 파일
25개의 경로·hash·크기가 모두 일치합니다. 선택 Cask trust(`true`), 전체 Tap
trust(`false`), 확인한 developer key 두 개와 환경 상태도 baseline과 같습니다.

공유 trust-store 파일의 raw hash는 관측 기간 중 달라졌으며 변경 주체와
원인은 **Unverified**입니다. Trust·developer 변경 명령, 우회나 store 복구는
수행하지 않았습니다. 대상 설정은 같지만 전체 store의 bytes 보존을 입증한
결과는 아닙니다. 현재 store를 유지하고 관련 없는 변경을 덮어쓰지 않습니다.

요청한 추가 읽기 전용 조사에서는 Git hook 설정, vendored style 도구 경로,
같은 시간대의 분리된 QA 근거, 현재 process metadata와 해당 시각의 shell
history·unified log를 확인했습니다. 공유 store의 writer를 특정할 근거는
찾지 못했습니다. 분리된 trust 파일은 공유 store와 다르며 시간대가 겹친다는
사실만으로 원인을 확정하지 않습니다. 변경 주체와 원인은 미확인으로 유지하고
복구나 설정 변경은 수행하지 않았습니다.

Build 26 GUI, 실기기 동작, 모드 readback, 설치·upgrade·Gatekeeper와 로그인·잠금·
절전·crash acceptance는 **NOT_RUN**입니다. 지원 범위는 Apple Silicon, macOS 26
이상과 확인한 ZEUSLAP P16KT profile 한 대이며 Developer ID와 공증 없이 ad hoc
서명을 유지합니다. 기존 로컬 beta.7/build 25 후보와 `--scan` 결과는
[native QA 기록](../qa/2026-10-12-native-build.md)에 별도 보존합니다.
