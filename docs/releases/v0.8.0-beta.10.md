### 변경과 검증

- 공개 beta.9/build 27과 같은 장기 인증서·identifier·기본 DR로
  beta.10/build 28을 준비했습니다.
- A9 최초 전환은 완료됐습니다. 사용자가 앱 GUI의 입력 모니터링과 손쉬운 사용
  모두 Allowed임을 확인한 뒤 정상 Quit했고 native PID 부재도 확인했습니다.
  개별 before 값은 미확인이며 매핑 Start는 실행하지 않았습니다.
- B10은 실행 파일 bytes·cdhash가 다르고 A9↔B10 DR 검사를 통과했습니다.
  정상 Homebrew beta.9 → beta.10 in-place upgrade 한 번을 통과했습니다.
  사용자가 같은 Mac·사용자·경로에서 재승인 없이 새 B10 GUI의 두 권한 모두
  Allowed임을 확인했습니다. **PASS_USER_REPORTED_ON_THIS_MAC**입니다.

위 표에 native 후보의 정확한 인증서·DR·실행 파일·DMG 식별을 기록했습니다.
빌드·패키징 각 한 번은 exit 0이며 앱·DMG 검사, 읽기 전용 내부 앱 비교와
정상 detach를 통과했습니다. 설치된 A9·바깥 디렉터리·이전 로컬 산출물은
native checkpoint에서 보존했고 당시 B10은 실행하지 않았습니다. 입력 [43개 manifest](v0.8.0-beta.10-inputs.json)는
정확한 공개 source/tag와 대조해 모두 일치했습니다. Beta.9 입력과 다른 것은 `VERSION`과
최종 Cask metadata입니다. 비치명적인 CLT linker search-path 경고는 로그에
유지하며 toolchain을 바꾸지 않았습니다. 바깥 DMG는 code signing하지 않았습니다.

Cask 문법과 동등한 Homebrew 규칙은 설치된 호환 `spoom 1.8.9`로 통과했습니다.
정확한 locked toolchain의 PASS는 아니며 online audit는 기존 합의에 따라
**BLOCKED**입니다. 공개 source/tag와 Cask Tap 식별은 위 표에 있으며 익명
공개 DMG·sidecar bytes는 native 후보와 같습니다. 정상 upgrade 한 번을
01:19:31 KST(2026-10-13 16:19:31 UTC)에 exit 0으로 마쳤습니다. 설치 파일 5개,
strict 인증서·DR, receipt와 바깥 device·inode를 확인했습니다. 환경설정·복구
hash와 선택 Cask/전체 Tap trust true/false도 보존했습니다.

A9 허용 baseline은 **PASS_USER_REPORTED**입니다. PID `35272`의 공개 경로·hash와
정상 Quit·native 부재를 확인한 뒤 새 B10 PID `60924`를 실행했습니다. 사용자가
앱 GUI의 beta.10/build 28과 두 권한 모두 재승인 없이 Allowed임을 확인했습니다.
01:27:59 KST에 같은 PID·경로·hash를, 01:28:03 KST에 상태 보존을 native로
재확인했습니다(2026-10-13 16:27:59/16:28:03 UTC). GUI 값은 사용자 보고이며
native 검사는 process 식별과 상태 보존을 입증합니다. 자동 GUI 조회 한 번은
native pipe가 닫혀 실패했습니다. Start나 권한 변경은 실행하지 않았으며 범위는
이 Mac의 같은 사용자·설치 경로입니다.

Upgrade 후 첫 assertion은 숫자 `CFBundleShortVersionString`을 잘못 비교해
중단됐습니다. `TouchMeReleaseVersion`으로 바로잡고 검증만 이어갔으며
upgrade를 다시 실행하지 않았습니다. 최초 실패는 기록에 유지합니다. 이전
release 9개·asset metadata 18개·tag ref 18개의 식별을 보존했습니다. 이후

Developer ID·공증이 없는 개인 self-signed beta이며 인증서 trust는 추가하지
않습니다. Fresh Gatekeeper·수신 Mac·실기기 acceptance는 **NOT_RUN**입니다.
