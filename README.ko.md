# macOS에서 P16KT 터치 화면 사용하기

Touch Me는 ZEUSLAP P16KT의 터치 입력을 선택한 화면에 맞춰 전달합니다. 메뉴 막대 앱을 실행하면 탭, 드래그, 더블 클릭과 두 손가락 스크롤을 사용할 수 있습니다. 현재 beta 버전은 `0.8.0-beta.1`입니다.

## 사용 환경 확인하기

현재 구현은 Apple Silicon과 macOS 26 이상에서 P16KT 한 대를 연결하는 환경을 대상으로 합니다. 기록된 실기기 검증 환경은 Apple M4 Max, macOS 26.7.1과 USB-C 직접 연결입니다.

| 항목 | 현재 범위 |
| --- | --- |
| 터치 패널 | ZEUSLAP P16KT; 확인한 USB 장치 `0x0457:0x0819` |
| 대상 화면 | 회전과 미러링을 사용하지 않는 외부 화면 |
| 권한 | 입력 모니터링과 손쉬운 사용 |
| 앱 언어 | 기본값 영어; 설정에서 English / 한국어 선택 |
| 배포 | Ad hoc arm64 앱과 디스크 이미지; 개인 Homebrew beta Tap |

다른 패널, Intel Mac과 이전 macOS 버전은 검증 기록이 없습니다. Touch Me를 시작하기 전에 다른 터치 매핑 프로그램을 중지하세요.

## 설치하고 매핑 시작하기

[v0.8.0-beta.1 release](https://github.com/soom-kang/touch-me/releases/tag/v0.8.0-beta.1)의 DMG와 checksum을 사용하거나 [개발 Workflow](Workflow.ko.md)에 따라 직접 빌드하세요. 로컬 이미지 경로는 `dist/touch-me-0.8.0-beta.1-arm64.dmg`입니다. Tap 설치, 수동 설치 앱과의 충돌 처리와 release 검사는 [Homebrew 배포](docs/Homebrew.ko.md)에서 확인하세요.

1. 디스크 이미지를 열고 **Touch Me.app**을 **Applications**로 끌어 복사하세요. 이미지를 추출한 뒤 설치한 앱을 여세요.
2. **시스템 설정 → 개인정보 보호 및 보안**을 여세요. **입력 모니터링**과 **손쉬운 사용**에서 Touch Me를 허용하세요.
3. P16KT를 USB-C로 연결하세요. Touch Me 메뉴 막대에서 **Settings / Proof**를 여세요. 한국어로 사용하려면 상단 **Language**에서 **한국어**를 선택하세요.
4. P16KT 화면을 선택하고 시험 창을 여세요. 창이 패널에 나타나는지 확인한 뒤 대상 화면 확인 항목을 선택하세요.
5. **매핑 시작**을 누르고 서로 떨어진 두 위치에서 탭 좌표를 확인하세요.

앱은 메뉴 막대에 표시됩니다. 설정 창을 닫아도 매핑은 계속됩니다.

설정 상단의 **Language / 언어**에서 **English** 또는 **한국어**를 선택하세요. 변경 즉시 적용하고 다음 실행에도 선택을 유지합니다. 언어를 바꿔도 실행 중인 매핑, 선택한 대상과 시험 창의 기록은 유지됩니다. macOS 대화상자와 시스템 설정은 자체 언어를 따릅니다.

Beta는 ad hoc 서명을 사용하며 공증하지 않았습니다. 다운로드한 앱은 첫 실행이 차단될 수 있습니다. 출처와 checksum을 확인한 뒤 [Apple의 수동 실행 승인 안내](https://support.apple.com/en-us/102445)를 따르세요. 승인 항목이 제공되더라도 실행 가능성을 보장하지는 않습니다.

## 터치와 실행 상태 제어하기

지원하는 제스처는 다음과 같습니다:

| 동작 | 제스처 |
| --- | --- |
| 클릭 또는 더블 클릭 | 한 번 또는 두 번 탭 |
| 드래그 | 한 손가락으로 누른 채 이동 |
| 세로 또는 가로 스크롤 | 두 손가락을 함께 이동 |
| 스크롤 후 드래그 시작 | 두 손가락을 모두 뗀 뒤 새 한 손가락 제스처 시작 |

**매핑 중지**를 누르면 입력을 해제하고 다음 실행에서도 중지 상태를 유지합니다. 매핑 중 종료하면 다시 시작할 의도를 저장합니다. 자동 재개하려면 저장한 화면과 USB 위치가 일치하고 두 권한이 모두 허용돼야 합니다.

절전, 사용자 세션 비활성화 또는 화면 구성 변경은 매핑을 안전하게 중지하고 저장된 재개 의도를 해제합니다. 잠에서 깨거나 세션으로 돌아와도 자동으로 시작하지 않습니다. 대상과 권한을 확인한 뒤 직접 매핑을 시작하세요. 정상 종료는 앞선 안전 중단이나 명시적 중지가 재개 의도를 해제하지 않은 경우에만 재개 의도를 유지합니다.

**로그인 시 시작**은 기본값이 꺼짐입니다. 앱을 Applications에 복사한 뒤 설정에서 켜세요. 로그인 시 시작은 앱을 여는 옵션이며, 매핑 재개 여부는 저장한 실행 상태에 따릅니다.

## 오류 복구 또는 앱 삭제하기

매핑 중에는 확인한 P16KT의 장치 모드를 임시로 변경합니다. 중지하거나 정상 종료하면 입력을 해제하고, 모드를 변경한 경우 원래 값으로 복구합니다. 복구에 실패하면 앱 종료가 차단될 수 있습니다.

| 상황 | 다음 행동 |
| --- | --- |
| 권한이 부족함 | 두 개인정보 보호 설정에서 Touch Me를 허용하고 앱을 새로 조회하세요 |
| 패널이나 화면이 바뀜 | 저장한 패널을 같은 USB 포트에 연결하고 화면을 다시 선택·확인하세요 |
| 장치 접근에 실패함 | 다른 매핑 프로그램을 중지하고 USB 연결을 확인하세요 |
| 장치 모드 복구에 실패함 | P16KT를 같은 USB 포트에 다시 연결하고 **매핑 중지**로 복구한 뒤 종료하세요 |

앱을 삭제하려면 **로그인 시 시작**을 끄고 매핑을 중지하세요. 앱을 종료한 뒤 휴지통으로 옮기세요. 이 절차는 저장한 환경설정을 삭제하지 않습니다.

## 기록된 검증 결과 확인하기

이 요약은 상세 개발 기록을 정리하면서 보존한 결과입니다. `Asia/Seoul` 기준 2026-10-07의 build 8 단독 검증을 다룹니다. 아래 입력 결과는 사용자 보고이며, 프로세스와 산출물 확인은 별도로 수행했습니다:

- 탭 좌표, 한 손가락 드래그와 정상 종료 후 입력 해제
- 사전 탭 없는 두 손가락 세로·가로 스크롤
- 더블 클릭 감지와 정상 종료 후 자동 재개
- 중지 상태 유지와 로그인 항목 등록·해제
- 개인용 디스크 이미지의 Finder 설치와 설치 후 매핑

이는 기록된 결과이며 재생성한 앱의 새 실기기 검증이 아닙니다. 실제 로그아웃·로그인 실행은 `NOT_RUN`, 자동 재개 후 가로 스크롤은 `NOT_RETESTED`입니다. 다른 매핑 프로그램의 개입 가능성이 있던 초기 시험은 단독 동작의 근거로 사용하지 않습니다.

장치 처리나 호환 범위를 바꾸기 전에 [검증 범위](Workflow.ko.md#변경에-맞는-최소-검증-선택하기)를 확인하세요.
